# 🌍 עולם המדינות

משחק אסטרטגיה אונליין על כדור הארץ. בוחרים שרת, מקימים מדינה על המפה עם שם ודגל, מגייסים צבא ונלחמים בחברים ובשחקנים מכל העולם.

## הרצה
- לחיצה כפולה על `start.bat`, או `node server.js`.
- הדפדפן נפתח בכתובת http://localhost:3000.

## מקשים
| מקש | פעולה |
|---|---|
| **E** | חנות: חיילים, טנקים, מטוסים, טילים, תושבים, בתים ומפעלים |
| **F** | שדרוגים: שטח, כלכלה, דיור, תעשייה, נשק, שריון ולוגיסטיקה |
| **H** | טיסה למדינה שלך |
| **Tab** | הצגה או הסתרה של הדירוג |
| **Enter** | צ'אט |
| **Esc** | סגירת חלונות |
| עכבר | גרירה מסובבת את הגלובוס, הגלגלת עושה זום, ולחיצה על מדינה פותחת את הפרטים שלה |

המקשים עובדים גם כשהמקלדת בעברית.

## איך משחקים
- **הקמה:** בוחרים שם ודגל (מוכן או תמונה מהמחשב), ואז לוחצים על יבשה בגלובוס. אין סיסמה: המחשב זוכר את המדינה שלך.
- **על המפה:** כל מה שיש לך מצויר בתוך השטח שלך: בתים, מפעלים, חיילים, טנקים, טילים, ומטוסים שחגים מעל המדינה.
- **מלחמה:** לוחצים על מדינה ואז על "תקוף". בוחרים על מה נלחמים (שטח, כלים או כסף) וכמה כוחות לשלוח. הטיל שטס על הגלובוס מראה מתי הצבא יגיע.
- **מגן:** למדינה חדשה יש מגן ל-5 דקות. מי שמפסיד בהגנה מקבל מגן ל-2 דקות. מי שתוקף מאבד את המגן שלו.

## לשחק עם חברים
- **אותה רשת:** שולחים לחברים את הכתובת שהשרת מדפיס, למשל `http://192.168.x.x:3000`.
- **מכל העולם:** מעלים את התיקייה לשירות אירוח שמריץ Node.js, למשל Render, עם פקודת הפעלה `npm start`.
- **שרת פרטי:** יוצרים אותו במסך הפתיחה ושולחים לחברים את הקוד.

הנתונים נשמרים בקובץ `data.json`.
